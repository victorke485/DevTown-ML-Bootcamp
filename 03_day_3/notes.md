# Unsupervised Learning

Machine is given unlabeled data and classifiers it into clusters of similar things.
- No labels needed.
- The goal is to find natural groups or patterns hiding in your data.
- Used in:
  - customer grouping
  - reccomendation systems
  - fraud detection
  - image compression
  
## Clustering
Is an algorithm that groups data together.

### K-Means Clustering
Splits your data into K groups by finding the 'center point' of each group.
k = number of groups ypu want
Elbow method is used to figure out the best value of k.

Example use cases:
- Customer Segentation: Businesses use K-means to automatically group customers with similar buying habits.
- Fraud detection in banking.
- Recommending products on shoping apps.
